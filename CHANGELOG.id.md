# Catatan Perubahan

[English](CHANGELOG.md) | **Bahasa Indonesia**

## 1.0.1 (2026-10-16)

### Ditambahkan
- Aplikasi Android untuk Google Play: WebView native dengan photo picker bawaan sistem, simpan langsung ke galeri, layar offline, dan warna status bar yang mengikuti tema
- Mode aplikasi di website: layar loading beranimasi, tampilan lebih ringkas, dan sentuhan yang terasa seperti aplikasi native
- Animasi proses: foto perlahan blur dengan partikel cahaya, lalu latar terhapus titik demi titik
- Halaman pendaftaran tester di `/testers` dengan Supabase
- Ikon maskable, Digital Asset Links, dan halaman cadangan offline di service worker
- Grafis Google Play di folder `store/`
- Workflow GitHub Actions yang membuat AAB dan APK bertanda tangan

### Diperbaiki
- Halaman melebar ke samping di HP setelah gambar diproses

### Diubah
- Ikon aplikasi baru
- Link donasi dan iklan disembunyikan di dalam aplikasi Android

## 1.0.0

- Rilis publik pertama website: hapus latar otomatis, Portrait HD, alat edit, slider perbandingan, ekspor PNG/JPG/WebP, mode terang dan gelap, PWA
